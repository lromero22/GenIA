TABLA: lk_pedidos
DESCRIPCION: Esta tabla contiene la identificación de cada vendedor, el estado del vendedor y el id del usuario al que fue asignado este vendedor
RELACIONES: Se relaciona con las tablas: lk_pedidos_cstm
COLUMNAS:
- id: Esta columna es de tipo Primary Key, char(36). Contiene el documento de identidad y el ciclo. Por ejemplo: 1000003259-202310, donde 1000003259 es el documento de identidad y 202310 es el ciclo. (La temporalidad de los ciclos es 3 semanas)
- deleted: Esta columna es de tipo tinyint(1). Contiene el estado de cada vendedor si fue eliminado o si esta activo. Por ejemplo: 0 significa que esta activo, y 1 que fue eliminado
- assigned_user_id: Esta columna es de tipo char(36). Contiene el id del usuario al que fue asignado un vendedor.

TABLA: lk_pedidos_cstm
DESCRIPCION: Esta tabla es una extension de la tabla 'lk_pedidos', . Contiene multiples detalles relacionados con el vendedor y el pedido.
QUERY EJEMPLO: SELECT leads.last_name, leads_cstm.identificacion_c FROM leads JOIN leads_cstm ON leads.id = leads_cstm.id_c WHERE leads_cstm.antiguedad_c > 50
COLUMNAS:
- id_c: Esta columna es de tipo Primary Key, char(36). Contiene el documento de identidad y el ciclo y se relaciona con la columna id, de la tabla lk_pedidos. Por ejemplo: 1000003259-202310, donde 1000003259 es el documento de identidad y 202310 es el ciclo. (La temporalidad de los ciclos es 3 semanas)
- ciclo_c: Esta columna es de tipo varchar(255). Contiene el numero de ciclo, que esta en formato AÑOCICLO. Por ejemplo: 202310, 2023 es el año, y 10 es el ciclo, cuya temporalidad es de 3 semanas
- valor_venta_sin_iva_c: Esta columna es de tipo varchar. Contiene el valor de la venta del vendedor sin el impuesto del IVA.
- pedidos_realizados_c: Esta columna es de tipo varchar. Contiene la cantidad de pedidos realizados en un ciclo.
- presupuesto_c: Esta columna es de tipo varchar. Contiene el presupuesto propuesto para ese vendedor en el ciclo indicado.
- fecha_de_entrega_2_c: Esta columna es de tipo date. Contiene la fecha de entrega del kit para el vendedor.
- semestre_c: Esta columna es de tipo varchar. Contiene el semestre en el que se realizo el pedido, descrito en letras: Por ejemplo: Primer
- frecuencia_proyectada_c: Esta columna es de tipo varchar. Contiene la frecuencia proyectada en la que el vendedor deberia realizar pedidos para cumplir el presupuesto
- inactividad_c: Esta columna es de tipo varchar. Contiene la cantidad de ciclos acumulados sin actividad de compra por parte del vendedor.
- frecuencia_c: Esta columna es de tipo varchar. Contiene la frecuencia en la que he vendedor ha realizado pedidos historicamente.

TABLA: leads
DESCRIPCION: Esta tabla contiene el id unico, datos y detalles especificos de los vendedores novaventa.
RELACIONES: Se relaciona con las tablas: leads_cstm
COLUMNAS:
- id: Esta columna es de tipo Primary Key, char. Contiene el identificador unico del vendedor, el cual se usa para cruzar esta informacion con otras tablas
- date_entered: Esta columna es de tipo datetime. Esta columna contiene la fecha en que ingreso el vendedor
- created_by: Esta columna es de tipo char. Contiene el usuario que creo la entrada de este vendedor en la base de datos
- description: Esta columna es de tipo text. Contiene detalles de las interacciones del vendedor novaventa, con las personas encargadas de gestionar sus pedidos.
- deleted: Esta columna es de tipo tinyint. Contiene el estado de cada vendedor si fue eliminado o si esta activo. Por ejemplo: 0 significa que esta activo, y 1 que fue eliminado
- assigned_user_id: Esta columna es de tipo char. Contiene el id del usuario al que fue asignado un vendedor.
- last_name: Esta columna es de tipo varchar. Contiene  el nombre completo del vendedor
- department: Esta columna es de tipo varchar. Contiene el departamento de Colombia en el que esta ubicado el vendedor.
- do_not_call: Esta columna es de tipo tinyint. Contiene la preferencia de cada vendedor a ser contactado por telefono. Por ejemplo: 0 significa que recibe llamadas, y 1 que no le gusta recibir llamadas.
- phone_mobile: Esta columna es de tipo varchar. Contiene el numero de telefono del vendedor
- primary_address_city: Esta columna es de tipo varchar. Contiene la ciudad de Colombia en la que esta ubicado el vendedor.
- primary_address_state: Esta columna es de tipo varchar. Contiene el numero de documento del vendedor.

- ultimo_estado_llamada_c: Esta columna es de tipo varchar. Contiene un resumen del estado de la ultima llamada que se tuvo con el vendedor

- orden_promedio_c: Esta columna es de tipo int. Contiene el valor promedio de orden que realiza el vendedor
- motiva_vender_novaventa_c: Esta columna es de tipo varchar. Contiene la motivacion del vendedor para vender productos novaventa.
- venta_acomulada_c: Esta columna es de tipo int. Contiene el total historico de ventas del vendedor.
- valor_necesario_c: Esta columna es de tipo int. Contiene el valor necesario para cumplir el presupuesto asignado.
- acompanamiento_por_whatsapp_c: Esta columna es de tipo tinyint. Contiene datos booleanos para indicar si vendedor recibe acompañamiento por WhatsApp.
- tipo_catalogo_c: Esta columna es de tipo varchar. Contiene la descripcion del tipo de catalago que usa el vendedor novaventa.
- pedido_rechazado_c: Esta columna es de tipo tinyint. Contiene un booleano que indica el estado del pedido. 0/NULL para aprobado, 1 para rechazado.
- dias_mora_c: Esta columna es de tipo int. Contiene la cantidad de dias en mora del vendedor.
- pedido_ciclo_anterior_c: Esta columna es de tipo tinyint. Contiene un numero booleano que indica si el vendedor realizo un pedido en el ciclo anterior. 0/NULL para No, 1 para Si.
- frecuencia_actual_c: Esta columna es de tipo int. Contiene la frecuencia actual de pedidos del vendedor 
- no_enviar_c: Esta columna es de tipo tinyint. Contiene un numero booleano que indica si se le debe enviar o no el pedido al vendedor. 0 para Si, 1 para No.
